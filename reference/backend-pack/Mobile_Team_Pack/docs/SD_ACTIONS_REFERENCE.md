# Connectum actions (the `/sd` commands)

Generated by `tools/postman/build.mjs` from the code; do not edit by hand. Every action is one WebSocket message: `/sd <action> {json}`; the reply is `{type:"sd", reqId, ok, data | error}`. How to connect and call: see the Postman collection (folder 4) or `tools/postman/sd-call.mjs`.

**Level** says who may call it. **slow** actions talk to another system (an application, Axpert, the consumer) and run on a separate lane so a slow answer never blocks the person's connection. Arguments marked `?` are optional.

330 actions.

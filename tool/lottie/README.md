Lottie files with warm colours have recoloured copies (name_blue.json), made by `python3 tool/lottie/recolor_lottie.py`; the code loads the copies, the originals stay untouched. The loading copies turn about a third of their lighter blues into violet #8B5CF6 and purple #6A3FD4 (`VIOLET_RULES`). The onboarding copies are blue only: the same kind of accents, but in cyanBlue, primary and primaryStrong (`BLUE_ONLY_RULES`), and any violet left goes to the nearest-luminance blue. The script prints the mapping and the share.
